不思异：九州

驾一辆旧车，从人间边境向西，把沿途的志怪与人情记进采风册。车轴、粮草、神志任何一项归零，旅程就会提前结束。

标准难度 · 车轴 74 / 粮草 88 / 神志 82

  • 车轴走路、过烂路、修车。归零＝车散。
  • 粮草每天吃、补给、换东西。归零＝断粮。
  • 神志见怪、走夜路、低语。归零＝失心。
  1. 打开「地图」，点一张路线卡，再点「点此启程」才出发。
  2. 抵达后先处理遭遇，再写一条采风；每次抵达可用一次补给。
  3. 采风 4 条，裂隙前会多出「焚志远走」。
  4. 讽 / 哀 / 谶 ≥3 条或多于颂，归中原走「实录」；其余走「粉饰」。
  5. 神志 ≤24 时进裂隙，会走向「失名」。

引言 · 永昌三年 · 长安

奉旨采风

风宪司新设风宪郎。皇帝把这个差事交给一个叫陆离的记事：沿九州西行，记录风土、异闻与民情，回来修一部《九州总志》。

明面上，这是一趟替王朝写书的差事。暗地里还有一道口谕：把韩凌君一党在州县的暴虐，一条一条记下来。

拨下的钱经过层层克扣，到陆离手上只剩百钱。旧车、纸笔，一名寡言的铁吏宛渠。陆离有肺疾，宛渠有水边的忌讳，你们还是出了西门。

西边的路越走越不像官道。地图画完的地方之外，还有人在活。

你的目的：采风入册，查证韩党。能带回多少真话，取决于你怎么走、怎么记、怎么交。
